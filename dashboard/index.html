Observatory Overview: Measuring India's Public Web Infrastructure

India operates over 10,000 public portals serving 900+ million citizens. Rather than testing small arbitrary samples or homepages in isolation, BharatGov Access performs a longitudinal, multi-page audit (Homepage, About Us, Contact, Online Services, Circulars) across 77 standardized dimensions with strict decoupling of schema validation from measurement success.

Total Registry: 2,390 Evaluated Sample: N=798 (33.4%) Gateway Geo-Block: N=1,592 (66.6%)
🛡️ Methodological Transparency & Measurement Rigor Note:

• Decoupled Validation: A record can be schema-valid (is_schema_valid = true) while its measurement failed (is_measurement_successful = false). Validation does not imply measurement success.

• HTTP 502/504 Root Cause: 66.6% of unreachability originates from state NIC / RailTel reverse proxies enforcing Geo-IP blocking against non-Indian datacenter traffic (e.g. US cloud node). These are classified as failure_root_cause = STATE_GATEWAY_GEO_BLOCK_OR_WAF.

• Zero Misleading Scores: Failed or unreachable requests are strictly assigned NaN / null for accessibility, performance, and WCAG violation counts (a timeout is never assigned a false score).

Guidelines for Indian Government Websites (GIGW 3.0) Compliance Analysis

The Ministry of Electronics and Information Technology (MeitY) mandates that all public portals must incorporate accessible navigation, skip-to-content links, regional languages, grievance integrations (CPGRAMS), and strict security headers. Our audit reveals where Indian government websites have successfully modernized and where structural gaps persist.

1. The S3WaaS Advantage

+34% Score

Districts deployed on NIC's standardized S3WaaS platform achieve an average accessibility score of 95.8, compared to 71.4 for bespoke state dynamic portals. S3WaaS guarantees native responsive viewports and GIGW toolbars by default.

2. Regional Script Deficit

71.2% English Only

While Central portals offer bilingual coverage (Hindi/English), 80.5% of district portals lack automated or manual localization into regional state official languages (e.g. Tamil, Bengali, Telugu, Kannada), presenting a barrier for 500M+ rural citizens.

3. Cryptographic Hygiene

HSTS < 22%

While 100% of active government domains support HTTPS encryption, only 21.7% enforce Strict-Transport-Security (HSTS). This omission allows man-in-the-middle SSL-stripping vulnerabilities on public Wi-Fi networks.

How to Use the BharatGov Access Dataset

The BharatGov Access dataset is packaged as versioned, immutable Apache Parquet, CSV, and JSONL distributions for academic research and public policy analytics. Below is a quickstart guide for researchers loading and analyzing the dataset in Python.

🐍 Python Quickstart (Pandas / Polars)

import pandas as pd

# Load latest versioned dataset release
df = pd.read_csv("resources/bharatgov_access_2.5.0.csv")

print(f"Total Portals: {len(df):,}")
print(f"Feature Dimensions: {len(df.columns)}")

# Group by governance level and compare accessibility
maturity_by_tier = df.groupby("government_level")[[
    "overall_accessibility_score",
    "gigw_accessibility_score",
    "is_multilingual",
    "has_hsts"
]].mean()

print(maturity_by_tier)
