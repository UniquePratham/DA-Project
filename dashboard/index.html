How to Use the BharatGov Access Census Dataset in Research

The BharatGov Access dataset is packaged as versioned, immutable Apache Parquet, CSV, and JSON records covering 12,092 government portals. Audited directly over domestic Indian infrastructure in Bangalore, this benchmark provides reproducible data for computer science, public policy, and e-governance researchers.

Python Quickstart (Pandas / PyArrow) python >= 3.9 
import pandas as pd

# Load clean 5-pillar census dataset (12,092 portals)
df = pd.read_parquet("resources/bharatgov_access_clean.parquet")
active = df[df["is_reachable"] == True]

# Mean Accessibility by governance tier
acc = active.groupby("government_level")["sub_accessibility_score"].mean()
print("Accessibility by Tier:\n", acc.round(1))

# S3WaaS vs Legacy ASP.NET comparison
arch = active.groupby("sub_cms_architecture")[[
    "sub_accessibility_score",
    "sub_security_headers_score",
    "sub_response_latency_ms"
]].mean()
print("\nCMS Framework Comparison:\n", arch.round(1))

Clean 5-Pillar Schema Dictionary (20 Standard Columns)

Strictly standardized, non-ambiguous schema eliminating noisy or unverified variables:

Column Name Data Type Core Pillar Description & Standards Alignment
domain_name string Metadata Registered domain identifier (e.g. meity.gov.in, varanasi.nic.in)
is_reachable boolean Reachability True if portal returned HTTP 200/300 from domestic Bangalore node
measurement_reason string Diagnostic Explicit diagnostic status reason (e.g. 200 OK — Active S3WaaS Drupal Deployment, DNS Deprecated)
sub_accessibility_score float (0–100) Pillar 1: Accessibility WCAG 2.1 AA score measuring image alt attributes, form labels, and HTML lang tags
sub_has_gigw_toolbar boolean Pillar 1: Accessibility MeitY GIGW 3.0 accessibility widget (A+/A- font resizers, contrast toggle, skip-to-content)
sub_response_latency_ms float (ms) Pillar 2: Performance Network Round-Trip Time / Time to First Byte (TTFB) measured from Bangalore
sub_lcp_est_sec float (sec) Pillar 2: Performance Estimated Largest Contentful Paint (LCP) based on TTFB and DOM asset payload size
sub_https_enforced boolean Pillar 3: Security Whether portal strictly mandates TLS/HTTPS encryption on canonical traffic
sub_security_headers_score float (0–100) Pillar 3: Security CERT-In security header score evaluating HSTS, CSP, X-Frame-Options, and X-Content-Type
sub_is_multilingual boolean Pillar 4: Inclusivity Presence of content/navigation in Indian 8th Schedule regional languages (Hindi, Tamil, Bengali, etc.)
sub_mobile_responsive boolean Pillar 4: Inclusivity Standard mobile viewport configuration (width=device-width, initial-scale=1.0)
sub_cms_architecture categorical Pillar 5: Architecture CMS framework: s3waas_drupal, custom_dynamic_cms, legacy_asp_net, modern_spa, or wordpress
sub_has_citizen_services boolean Pillar 5: Interactivity Native search bar and citizen public grievance integration (CPGRAMS, Samadhan, Jan Sunwai)
observatory_maturity_score float (0–100) Composite Index Multidimensional weighted maturity score synthesizing all 5 core pillars
