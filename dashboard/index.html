    The five-pillar standard

    10 sub-features · 20 columns

    An earlier iteration carried more than seventy uncalibrated columns. Most were correlated restatements of the same measurement, which makes a composite index arbitrary. The standard now holds exactly five orthogonal pillars and two defensible sub-features each, every one traceable to a published specification.

    Composite index

    Weighted, 0–100

    The composite is a fixed linear weighting, not a fitted model. Accessibility carries the largest weight because it is the only pillar with a statutory obligation behind it under the Rights of Persons with Disabilities Act. Security follows because header absence is a measurable defect rather than a judgement call.

    Speed is scored as max(0, 100 − 15 × LCP), so a portal at the 2.5 s Core Web Vitals threshold scores 62.5 on that term and a portal at 6 s scores zero. The two binary reach terms are deliberately small: they describe coverage, not quality.

    Method and reproduction

    Versioned release

    The dataset ships as immutable Parquet, CSV and JSON. Everything on this page is derived from the same release, so a reader can reproduce any figure here without trusting the interface.

    Why the vantage point matters

    Measuring Indian government infrastructure from an overseas cloud region produces a systematic false negative. State data centres, NIC gateways and several departmental reverse proxies drop or reset foreign traffic at the perimeter, so a crawler in Frankfurt records a timeout on a portal that serves citizens normally.

    Every measurement in this release originates inside the domestic peering fabric. That single change moves the observed reachability rate by tens of percentage points and is the reason the census is worth publishing at all.

    Reproduce a figure

    Python 3.9+pandas · pyarrow
    import pandas as pd

df = pd.read_parquet("resources/bharatgov_access_clean.parquet")
live = df[df["is_reachable"]]

# Figure 1 — mean composite maturity per tier
tier = live.groupby("government_level")["observatory_maturity_score"]
print(tier.agg(["count", "mean"]).round(1))

# Figure 5 — platform distribution, unreachable excluded
print(live["sub_cms_architecture"].value_counts())

    Known limits

    • 01

      Structural, not rendered

      Accessibility is scored from markup: alternative text, form labels, language declaration and skip links. It does not execute a screen reader, so it cannot detect a focus trap or a mislabelled control.

    • 02

      LCP is estimated

      Largest Contentful Paint is derived from time to first byte and document payload rather than measured in a browser. It ranks portals correctly but should not be quoted as a field measurement.

    • 03

      One observation per domain

      Each domain is measured once per release. Longitudinal claims require comparing releases, not re-reading a single one.

    • 04

      Registration is not usage

      A registered domain is not necessarily a portal citizens use. The census measures what is published, not what is visited.

    Future — Global Observatory

    Planned expansion

    The India census is complete. The next phase measures other countries from inside those countries, using the same tools and the same timeouts, so the comparison is like for like. Everything on this page is either measured today or explicitly marked as planned.

    A · What changes and what does not

    A government website can only be judged from the network its citizens use. A portal that answers in 200 ms from Frankfurt and times out from Lagos is not a slow portal; it is a portal with a geography. Measuring it from the wrong place produces a number that looks precise and means nothing.

    The global observatory therefore provisions a measurement node inside each target country, runs the same five-pillar audit, uploads the evidence to central storage, and destroys the node. Compute is temporary. The dataset, the provenance and the methodology are permanent.

    What does not change: the tools, the timeouts, the safety governor, and the rule that a metric we did not measure is stored as null rather than zero.

        B · Worldwide coverage

        Derived from real cloud regions

        A country is marked operational only when a datacentre physically inside it exists. Where none exists, the country is marked planned or unsupported rather than measured from a neighbour, because a foreign probe cannot support a domestic claim.

        C · The eight research dimensions

        Each dimension is reported separately. They are not collapsed into a single score, because a country can be accessible and insecure at the same time, and averaging hides exactly that.
